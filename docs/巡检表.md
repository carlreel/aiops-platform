## 一、日巡检（每个工作日 09:00，约 5 分钟）

```bash
make health      # 一条命令跑完下面 1-8 项
```

| # | 检查项 | 方法 | 正常标准 | 异常处置 |
|---|---|---|---|---|
| 1 | 容器状态 | `docker compose ps` | 6 个服务 Up，无 unhealthy | 看 `docker logs <名>` → 重启 → 仍失败按应急预案 P1 |
| 2 | 服务端口 | 8000/9090/3000/5432 可连 | 全部可连 | 查容器状态 → 查端口冲突 `ss -tlnp` |
| 3 | 磁盘使用 | `df -h /` | < 80% | 清镜像 `docker system prune -af`、清日志、清旧备份 |
| 4 | 可用内存 | `free -h` | 可用 > 15% | 查是否模型重复加载；限 `OLLAMA_NUM_PARALLEL=1` |
| 5 | 依赖健康 | `curl -s :8000/health` | `db:up` 且 `ollama:up` | 分别排查数据库容器 / Ollama 进程 |
| 6 | 接口可用 | `curl -s :8000/healthz` | 返回 200 | 查 rag-api 日志 |
| 7 | 错误日志 | `docker logs --since 1h aiops-rag-api \| grep -ci error` | 0 条 | 逐条定性：偶发超时可不处理，连续报错必须定位 |
| 8 | 备份新鲜度 | `ls -lh backup/` | 最近备份 < 48h | 手动 `make backup`，查 crontab 是否生效 |

## 二、周巡检（每周一，约 20 分钟）

| # | 检查项 | 方法 | 正常标准 | 异常处置 |
|---|---|---|---|---|
| 1 | 备份可恢复性 | 在测试库 `psql -f` 导入最新 dump | 导入无错、行数一致 | 备份不可用等于没有备份 → 立即重建备份任务 |
| 2 | 告警规则有效性 | Prometheus 页面 `Alerts` 标签 | 规则加载、无 `inactive` 错误 | 改 `alerts.yml` 后 `restart prometheus` |
| 3 | 指标采集完整性 | `localhost:9090/targets` | 4 个 target 全 UP | 查对应 exporter 容器 |
| 4 | 磁盘趋势 | Grafana 查看 7 天曲线 | 斜率平缓，无锯齿 | 突增需定位来源（日志 / 镜像 / 数据） |
| 5 | 知识库规模 | `curl :8000/stats` | 文档数符合预期 | 异常减少说明数据被删，查操作记录 |
| 6 | 镜像与容器数量 | `docker images \| wc -l` | 无大量 dangling 镜像 | `docker image prune -f` |
| 7 | 账号与密钥 | 检查 `.env` 是否被提交 | 未被 git 跟踪 | `git rm --cached .env` 并加入 `.gitignore` |

## 三、月巡检（每月首个工作日，约 1 小时）

| # | 检查项 | 正常标准 | 说明 |
|---|---|---|---|
| 1 | 系统补丁 | 无高危未打补丁 | `apt list --upgradable` |
| 2 | 证书到期 | 剩余 > 30 天 | `openssl x509 -enddate -noout -in cert.pem` |
| 3 | 恢复演练 | 完整做一次「删库 → 恢复」 | 记录 RTO（恢复耗时） |
| 4 | 容量评估 | 磁盘/内存余量支持未来 3 个月增长 | 按周增长率外推 |
| 5 | 告警复盘 | 本月 P1/P2 告警均有处置记录 | 无记录的告警等于噪音 |
| 6 | 文档同步 | 部署手册与实际一致 | 改过配置必须同步改文档 |
| 7 | 依赖版本 | 无已知高危 CVE | `docker compose images` 对照官方公告 |

## 四、巡检异常分级与上报

| 级别 | 判定 | 响应时限 | 通知方式 |
|---|---|---|---|
| P1 | 服务整体不可用、数据损坏 | 15 分钟内 | 电话 + 群 |
| P2 | 核心功能降级（检索不可用、生成超时） | 1 小时内 | 群 |
| P3 | 单点告警、性能下降、容量预警 | 当日 | 记录，周会同步 |
| P4 | 文档不一致、待优化项 | 本周内 | 记录 |

---

## 五、填写规范

1. 巡检结果**当天填写**，不得补填。
2. 异常项必须在「异常说明」写清：现象、处置动作、结果。
3. 连续 3 天同一项异常 → 升级为问题单，不能一直"处置"。
4. 交接时巡检表连同备份清单一起移交。
