# 离线交付包清单

> 场景：政务 / 公安等**内网不能访问外网**的环境，所有镜像、模型、依赖必须提前打包带入。
> 原则：**在联网机器上把所有东西准备齐，到现场只做 `load` 和 `up`。**

## 二、打包步骤（联网机器）

```bash
# 1) 镜像
mkdir -p offline/images
for img in pgvector/pgvector:pg16 prom/prometheus:v2.55.1 grafana/grafana:11.3.0 \
           prom/node-exporter:v1.8.2 gcr.io/cadvisor/cadvisor:v0.49.1 python:3.12-slim; do
  docker pull "$img"
  docker save "$img" -o "offline/images/$(echo "$img" | tr '/:' '__').tar"
done

# 2) 自研镜像
docker compose build
docker save aiops-platform-rag-api:latest -o offline/images/aiops-rag-api.tar

# 3) 模型（Ollama 原生导出）
ollama pull qwen3:4b && ollama pull bge-m3
# 方式一：直接复制模型目录（最简单、最可靠）
#   Windows: C:\Users\<用户>\.ollama\models
#   Linux:   /usr/share/ollama/.ollama/models 或 ~/.ollama/models
tar -czf offline/models.tar.gz -C ~/.ollama models

# 4) Python 依赖（现场需要重新 build 时用）
pip download -r rag-api/requirements.txt -d offline/wheels/

# 5) 代码
git archive --format=tar.gz -o offline/aiops-platform.tar.gz HEAD

# 6) 校验
cd offline && sha256sum $(find . -type f -name '*.tar*') > SHA256SUMS
```

## 三、现场部署步骤（断网机器）

```bash
# 1) 校验完整性（必须做，传输损坏是最常见的现场事故）
sha256sum -c SHA256SUMS

# 2) 导入镜像
for f in images/*.tar; do docker load -i "$f"; done
docker images | grep -E 'pgvector|prometheus|grafana|rag-api'

# 3) 恢复模型
tar -xzf models.tar.gz -C ~/
#    或指向已有目录：export OLLAMA_MODELS=/data/ollama/models
systemctl restart ollama
ollama list          # 必须能看到 qwen3:4b 与 bge-m3

# 4) 部署
tar -xzf aiops-platform.tar.gz && cd aiops-platform
cp .env.example .env && vi .env      # 改密码、OLLAMA_BASE_URL
docker compose up -d

# 5) 验收
curl -s localhost:8000/health
curl -X POST localhost:8000/ingest -H 'Content-Type: application/json' \
     -d '{"doc_id":"smoke","text":"离线部署验收测试文本。"}'
curl -X POST localhost:8000/query -H 'Content-Type: application/json' \
     -d '{"question":"这是什么测试？"}'
```

## 四、离线环境特别注意

| 事项 | 问题 | 处置 |
|---|---|---|
| 时间同步 | 内网无 NTP，时间漂移导致 TLS 与日志错乱 | 配置内网 NTP 源，或部署前校时 |
| 证书 | 无法申请公网证书 | 使用内部 CA 签发，客户端导入根证书 |
| 镜像加速 | 现场无外网，不能用 registry mirror | 全部走 `docker load`，不用 `pull` |
| 依赖 | 构建时 `pip install` 会失败 | 用 `--find-links=wheels --no-index` 离线安装 |
| 模型更新 | 无法在线 `ollama pull` | 复制 models 目录，或用本地 GGUF + `ollama create` |
| 日志留存 | 等保要求日志留存 6 个月 | 配置 `max-size` + 定期归档到指定目录 |
| 缺省密码 | 现场容易漏改 | 部署清单里把改密码列为强制项，交付前复核 |
